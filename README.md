# 🎵 SQL Music Store Data Analysis

> Analyzed a digital music store database using advanced SQL queries to uncover business insights on customers, artists, and sales performance.

## 📊 Project Highlights

- **Complex Queries:** Written using JOINs, subqueries, GROUP BY, and window functions
- **Customer Intelligence:** Identified top spending customers and high-value markets
- **Sales Insights:** Uncovered best performing artists, genres, and sales regions
- **Business KPIs:** Extracted actionable metrics to support data-driven decisions

## 🛠️ Tech Stack

- **Language:** SQL
- **Database:** PostgreSQL
- **Tools:** pgAdmin, Jupyter Notebook

## 🔍 Key Questions Answered

| Business Question | Approach |
|-------------------|----------|
| Who are the top customers by revenue? | Aggregation + ORDER BY |
| Which artists generate most sales? | JOINs across multiple tables |
| What are the best performing regions? | GROUP BY + window functions |
| Which genres are most popular? | Subqueries + COUNT |
